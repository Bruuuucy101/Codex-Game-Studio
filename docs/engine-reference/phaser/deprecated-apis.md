# Phaser 3 API cautions

Last verified: 2026-09-21.

Do not copy Phaser 2 State or Phaser 4 examples into the pinned Phaser 3 Scene API. For a reported deprecated method, check the installed declarations and corresponding tagged source before proposing its replacement; no exhaustive deprecation list is claimed here. Phaser includes TypeScript declarations; do not install a speculative @types/phaser package.

Sources: [3.90.0 package](https://raw.githubusercontent.com/phaserjs/phaser/v3.90.0/package.json), [Scene guide](https://docs.phaser.io/phaser/concepts/scenes).
